# Changelog

All notable changes to ThemeKit are documented here.

## 1.0.4

### Added

- A command-line installer that creates a Concrete CMS theme from the supplied
  PHP skeleton, Sass stylesheets, and TypeScript files.
- A system-pages installer that copies system page views and configures the
  theme for the not-found, forbidden, and maintenance-mode pages.
- Starter `webpack.mix.js` and `tsconfig.json` configuration.
- npm dependencies for TypeScript, webpack, Bootstrap, Popper, and Bootstrap
  Icons.
